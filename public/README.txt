このフォルダ（public/）に配置したファイルは、
Vite のビルド時に dist/ へそのままコピーされます。

【必須: ファビコンファイルの配置手順】

  1. favicon.ico（紫の兜アイコン）をこのフォルダに配置
     → ブラウザタブ・ブックマークに使用されます

  2. apple-touch-icon.png（180×180px 推奨）をこのフォルダに配置
     → iOS ホーム画面追加時に使用されます

  配置後の構成イメージ:
  public/
  ├── favicon.ico            ← ★ ここに配置
  ├── apple-touch-icon.png   ← ★ ここに配置
  └── README.txt             ← このファイル

  ※ ファイルが未配置の場合、ブラウザはデフォルトアイコンを表示します。
     エラーにはなりませんが、ブランディングのために必ず配置してください。

【デプロイ時の注意】

  npm run build を実行後、dist/ フォルダが生成されます。
  Cloudflare Workers へは wrangler.toml の設定に従って
  npx wrangler deploy でデプロイしてください。
